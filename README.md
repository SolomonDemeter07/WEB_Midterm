# Warhammer 40,000 | Beginner's Guide

## Project Description
This repository contains the Midterm Project for the Web Frontend course. It is a multi-page, fully responsive website dedicated to introducing newcomers to the grimdark universe of Warhammer 40,000. The project demonstrates a strong understanding of semantic HTML5, custom CSS styling, and the Bootstrap 5 framework.

## Website Structure
The website consists of 5 interconnected pages connected by a global fixed navigation bar:
* **Home (index.html):** Introduction to the universe with a responsive Hero section.
* **Tabletop (tabletop.html):** A guide to the miniature wargame, utilizing CSS Grid for a responsive faction gallery.
* **Lore & Books (lore.html):** A structured reading order using a custom-styled HTML Table.
* **Video Games (games.html):** Game recommendations built with Flexbox to create equal-height, interactive cards.
* **Contact (contact.html):** A themed enlistment HTML Form for users to join a faction.

## Key Technologies & Features
* **Semantic HTML5:** Proper use of header, main, section, nav, and structured forms.
* **Advanced CSS:** Custom hover animations, Flexbox, and CSS Grid layouts.
* **Bootstrap 5:** Implementation of the Bootstrap container system, utility classes, and a mobile-responsive navbar.
* **Responsive Design:** Media queries implemented for optimal viewing on mobile and tablet devices.
